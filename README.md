# 体素模型编辑器 (Voxel Model Editor)

一个基于 React + Three.js 的 3D 模型编辑器，提供**三大模式**：顶点编辑、体素化、CNC 切削模拟。

## ✨ 三大模式

### 1. 顶点编辑模式 (Vertex Edit Mode)
- 显示模型的顶点手柄（可交互小球）
- **拖拽顶点**实时变形模型
- 可通过微调按钮精确调整选中顶点的 XYZ 坐标
- 支持多种基础几何体：立方体、球体、圆柱体、圆环、锥体
- 可调节细分度（顶点密度）
- 一键重置所有顶点

![顶点编辑模式](docs/截屏2026-08-12%2009.14.20.png)

### 2. 体素模式 (Voxel Mode)
- 将模型（包括编辑变形后的）**体素化**为 3D 方块网格
- 基于 **射线投射 (Ray Casting)** 算法，精确判断每个体素是否在模型内部
- 可调节体素分辨率（4³ ~ 48³）
- 支持仅显示外壳体素（表面层）
- 可调节体素间隙、渐变颜色
- 实时显示体素统计（总数、网格单元数、填充率）

![体素模式](docs/截屏2026-08-12%2009.14.52.png)

### 3. CNC 切削模拟模式 (CNC Machining Mode)
- **G-code 解析**：支持 G00/G01/G02/G03/G81 等指令
- **高度图切削引擎**：N×N 细分顶面网格，刀具经过时实时切削
- **8 种刀具库**：端铣刀（3 种）、球刀（2 种）、钻头（3 种）
- **8 种材质**：铝合金、碳钢、黄铜、亚克力、木材等
- **实时动画回放**：时间轴拖拽、变速播放（0.5× ~ 5×）
- **DRO 数字读数**：实时显示 X/Y/Z 坐标、主轴转速、进给率
- **6 种示例程序**：圆形槽、钻孔、螺旋花纹、心形雕刻、CNC 文字、网格阵列
- **工业级 UI**：工作台 T 型槽、主轴装配体、切削指示灯

![CNC切削模拟](docs/截屏2026-08-12%2009.15.28.png)

## 📌 体素化算法说明

体素化使用 **轴线批量射线投射** 优化算法：

1. 计算模型包围盒，建立均匀 3D 网格
2. 对每个网格列（固定 Y,Z），沿 X 轴发射单条射线
3. 收集射线与模型表面的所有交点，按 X 排序
4. 用**奇偶规则**判断该列上每个 X 体素的内外状态

复杂度从 O(N³ × raycast) 降低到 O(N² × raycast)，大幅提升性能。

### CNC 切削 — 高度图盖印 (Heightmap Stamping)

1. 工件 = 长方体 + N×N 细分顶面网格
2. 每个网格顶点有高度值（0=未切削，负值=切削深度）
3. 刀具沿 G-code 路径移动时，在高度图上盖印横截面
4. 不同刀具产生不同切削轮廓：
   - **端铣刀**：平底圆盘（均匀深度）
   - **球刀**：球形底部（边缘渐浅曲面）
   - **钻头**：尖头（中心深、边缘浅）
5. 渲染时将高度值位移到顶点 Y 坐标，实现实时形变
